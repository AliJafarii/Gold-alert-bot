# نبض بازار

سرویس تلگرام و بله برای بررسی قیمت طلای 18 عیار و سکه، محاسبه حباب سکه، و ارسال هشدار خرید/فروش.

## راه‌اندازی

1. فایل .env.example را به .env کپی کن.
2. مقدار TELEGRAM_BOT_TOKEN و TELEGRAM_CHAT_ID را برای تلگرام پر کن.
3. برای بله، مقدار BALE_BOT_TOKEN و BALE_CHAT_ID را هم پر کن.
4. دستور npm start را اجرا کن.

## تست بدون تلگرام

دستور npm run check یک گزارش فوری از قیمت، میانگین منابع، رفتار ذخیره‌شده، و حباب چاپ می‌کند.

## فرمان‌های تلگرام و بله

- /start: شروع و نمایش وضعیت
- /check: بررسی فوری قیمت و حباب
- /settings: نمایش تنظیمات فعلی
- /notify: تنظیم بازه دریافت گزارش
- /notify 5: تنظیم بازه دلخواه؛ مثال یعنی هر ۵ دقیقه
- /notify off: خاموش کردن گزارش‌های دوره‌ای

## فرمول

تنظیمات مهم در فایل .env:

- TELEGRAM_BOT_TOKEN: توکن تلگرام
- TELEGRAM_CHAT_ID: مقصد پیام هشدار
- ADMIN_CHAT_IDS: چت‌آیدی ادمین‌ها برای هشدار خطا/منبع پرت، جداشده با ویرگول
- BALE_BOT_TOKEN: توکن بله؛ اگر خالی باشد سمت بله روشن نمی‌شود
- BALE_CHAT_ID: مقصد پیش‌فرض پیام هشدار در بله
- BALE_ADMIN_CHAT_IDS: چت‌آیدی ادمین‌های بله، جداشده با ویرگول
- BALE_API_BASE_URL: آدرس API بله، پیش‌فرض https://tapi.bale.ai/bot
- ENABLED_SOURCES: منابع فعال قیمت مثل tgju,tala,tajnoghreh,tradingview,bale,telegram
- BALE_MARKET_CHANNELS: کانال‌های بله برای خواندن آخرین پیام قیمت، جداشده با ویرگول
- TELEGRAM_MARKET_CHANNELS: کانال‌های تلگرام برای خواندن آخرین پیام قیمت، جداشده با ویرگول
- SOURCE_MAX_AGE_HOURS: حداکثر عمر مجاز داده منبع؛ داده قدیمی از میانگین حذف می‌شود
- SOURCE_OUTLIER_PERCENT: درصد اختلاف مجاز با median منابع؛ عدد پرت از میانگین حذف می‌شود
- ADMIN_ALERT_STATE_FILE: فایل state برای جلوگیری از تکرار هشدارهای ادمین
- DATABASE_FILE: فایل SQLite برای کاربران و تنظیمات نوتیف
- DEFAULT_NOTIFICATION_INTERVAL_MINUTES: بازه پیش‌فرض نوتیف برای کاربر جدید
- TRADINGVIEW_TICKERS: نمادهای TradingView برای سیگنال جهانی، پیش‌فرض TVC:GOLD,TVC:SILVER,OANDA:XAUUSD
- TRADINGVIEW_GOLD_TICKER: نماد مرجع طلا در TradingView، پیش‌فرض TVC:GOLD
- TRADINGVIEW_SILVER_TICKER: نماد مرجع نقره در TradingView، پیش‌فرض TVC:SILVER
- BUY_BUBBLE_PERCENT: آستانه خرید، پیش‌فرض منفی 5
- SELL_BUBBLE_PERCENT: آستانه فروش، پیش‌فرض مثبت 5
- HISTORY_FILE: فایل ذخیره تاریخچه برای تحلیل رفتار قیمت

ارزش ذاتی سکه از میانگین قیمت گرم طلای 18 عیار محاسبه می‌شود:

intrinsic = gold18Price * coinWeightGrams * (coinPurity / goldPricePurity)
bubble = coinMarketPrice - intrinsic
bubblePercent = bubble / intrinsic * 100

## TradingView

وقتی `tradingview` داخل `ENABLED_SOURCES` فعال باشد، سرویس از TradingView scanner برای
اونس جهانی طلا و نقره، درصد تغییر، RSI، میانگین‌های متحرک، و خلاصه تکنیکال ۱ساعته
و ۴ساعته استفاده می‌کند. این داده منبع اصلی قیمت داخلی ایران نیست؛ فقط لایه
سیگنال جهانی است تا جمع‌بندی خرید/فروش محتاط‌تر شود.

## نوتیف کاربرمحور

هر کاربر می‌تواند بازه دریافت گزارش خودش را داشته باشد. گزینه‌های آماده داخل
`/notify` شامل ۱۰ دقیقه، ۳۰ دقیقه، ۱ ساعت، ۲ ساعت، ۶ ساعت، ۱۲ ساعت و ۲۴ ساعت
است. بازه دلخواه هم با `/notify <minutes>` تنظیم می‌شود؛ مثلاً `/notify 5`.
در تلگرام دکمه‌های inline برای انتخاب بازه هم فعال است. در بله، فرمان‌های
`/notify 10`، `/notify 60`، `/notify on` و `/notify off` همان کار را انجام
می‌دهند.

دیتابیس سبک SQLite است و فعلاً این مدل را دارد:

- `users`: چت‌آیدی، نام، username، وضعیت ادمین، زمان ایجاد/بروزرسانی
- `notification_settings`: چت‌آیدی، بازه نوتیف، روشن/خاموش بودن، آخرین ارسال

چت‌آیدی‌های بله با پیشوند `bale:` داخل دیتابیس ذخیره می‌شوند تا نوتیف‌ها و
کاربرهای دو پلتفرم از هم جدا بمانند.

گزارش دوره‌ای بر اساس همین تنظیمات ارسال می‌شود؛ اما `/check` همیشه بررسی فوری
می‌گیرد.

## کانال‌های بله و تلگرام

وقتی `bale` یا `telegram` داخل `ENABLED_SOURCES` فعال باشد، سرویس هر بار آخرین
پیام قابل‌تشخیص قیمت را از کانال‌های تنظیم‌شده می‌خواند. پیام‌های خبری، تبلیغاتی
یا متن‌هایی که حداقل چند قیمت اصلی بازار را ندارند، منبع قیمت حساب نمی‌شوند. منبع
ثابت `external` هنوز برای فرمان دستی `/source` باقی مانده، ولی برای کانال
`akhbardollar` دیگر از فایل ثابت استفاده نمی‌شود.

## پنل ادمین و سلامت منابع

فرمان‌های `/admin` و `/sources` فقط برای چت‌آیدی‌های `ADMIN_CHAT_IDS` فعال هستند.
سرویس قبل از میانگین‌گیری، هر منبع را از نظر قدیمی بودن و عدد پرت بررسی می‌کند.
اگر منبعی خطا بدهد، قدیمی باشد، یا اختلاف غیرعادی با median منابع داشته باشد، از
میانگین همان شاخص حذف می‌شود و فقط به ادمین هشدار داده می‌شود. هشدارهای تکراری
تا وقتی همان مشکل فعال است دوباره ارسال نمی‌شوند.
